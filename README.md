# Personal Portfolio

This is a standalone project for building a personal portfolio website for job applications.

## Purpose

- Present selected projects and case studies.
- Collect resume materials, screenshots, writing, and project links.
- Build a polished website that can be shared with recruiters and hiring teams.

## Project Structure

- `site/` - portfolio website source files.
- `assets/` - images, screenshots, icons, and downloadable files.
- `case-studies/` - project writeups and supporting notes.
- `resume/` - resume versions and role-specific summaries.

## Direction Options

- Product/design portfolio
- Frontend or full-stack engineering portfolio
- AI/productivity tool portfolio
- Mixed personal brand and project showcase
